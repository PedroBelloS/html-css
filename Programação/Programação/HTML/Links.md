dentro da tag ao do lado do URL sempre usar target="_blank" para ele não sobrepor a aba do seu site. Caso seja link externo usar  rel="external" 

Usar tambem dentro da tag a do lado do q vc envelopou o rel="next" caso for uma segunda pagina em diante 

Se for um pagina pra trás colocar rel="prev"

Se você for fazer um site e tiver q colocar um site n confiavel na tag a use rel="nofollow"

se fizer dentro de uma pasta use ../ para voltar uma pasta dentro do " da tag a (Exemplo: Volte <p><a href="../pag02.html">aqui</a></p>)
