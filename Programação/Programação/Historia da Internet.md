Historia da Internet

(1969 e 1970)

(ARPANET)
Internet: sendo um conjunto de varias redes

O Inicio da Internet surgiu na Guerra Fria com intenção de se comunicar entre bases militares e fazer backup de informações entre as mesmas.
Com isso foi criado o NCP mas para se comunicar a rede toda parava e só 2 computadores se comunicavam, então em 72 criaram o TCP que era pra corrigir o problema do NCP e o IP para identificar os computadores (Protocolo TCP/IP).

Anos Depois a ARPANET foi dividia em três a MILNET (Militar), a NSFNET (entre universidades), e a Comercial, então deram o nome de Interconnect Networking mas foram simplificando até se tornar o termo isolado Internet e foi evoluindo tecnologicamente tambem até oq conhecemos hoje.

Existem varios cabos submarinos por baixo da agua ligando todos os continentes.

Sinais de Computação são representados como 0 e 1
sendo eles os bit.
Mas para o computador representar os dados é formado um conjunto com no minimo 8 bits (01000001) sendo eles os byte

Código Multibyte (UTF-8) utiliza de 1 a 4 bytes pra representar letras, simbulos caracteres acentuados e até emojis

O comptutador só entende ondas binarias
Sequencia de bytes são chamados de multiplos

1024 bytes = 1KB
