Estrutura básica do C 

#include <stdio.h> - é a biblioteca do C (tem outras também) e é ele que define algumas funções tipo o printf();

O programa sempre começa no main sempre dentro das chaves

o printf("Hunter x Hunter); é uma declaração([Statements]) para deixar o texto na tela

se o programa sempre retornar 0 quer dizer que ele não deu "ruim"

> O C ignora espaços extras e espaços em branco no codigo, assim como no Html as declarações terminam com ;

> As declarações são executadas uma por uma na ordem que são escritas.

---

Sempre coloque "" (aspas duplas) dentro do printf

Para separar as linhas na saida use \n

Exemplo:

#include <stdio.h>  
  
int main() {  
  printf("Fire Force!**\n**");  
  printf(" Soul Eater.");  
  return 0;  
}

> Com 2 \n tu pula uma linha 
> 
> printf("Kagurabachi!**\n\n**");
